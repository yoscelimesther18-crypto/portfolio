Chatbot de Atención al Cliente

Chatbot inteligente de atención al cliente que utiliza procesamiento de lenguaje natural para responder consultas frecuentes, gestionar tickets de soporte y escalar casos complejos a agentes humanos.

Amazon Lex AWS Lambda DynamoDB Python JavaScript

Este proyecto demuestra la implementación de un chatbot conversacional para atención al cliente utilizando Amazon Lex como motor de comprensión de lenguaje natural. Las funciones Lambda procesan las intenciones del usuario y consultan DynamoDB para obtener información relevante en tiempo real.

Arquitectura: Usuario → Amazon Lex → AWS Lambda → DynamoDB

Demo AWS

Plataforma Serverless de Procesamiento de Datos

Pipeline serverless de procesamiento de datos que ingesta, transforma y sirve información a través de una API REST. Diseñado para escalar automáticamente según la demanda sin gestión de servidores.

AWS S3 AWS Lambda DynamoDB API Gateway Node.js

Esta plataforma implementa un flujo completo de procesamiento de datos sin servidores. Los archivos se cargan en S3, lo que dispara funciones Lambda para transformar y almacenar los datos en DynamoDB. Una API REST construida con API Gateway expone los datos procesados al frontend.

Arquitectura: S3 → AWS Lambda → DynamoDB → API Gateway → Frontend
